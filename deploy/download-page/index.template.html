Good to know

Google Play Protect shows a warning. Is it safe?

The warning appears because the app is not on Google Play yet. If you downloaded it from this page, choose “Install anyway”. You can check the file first with the fingerprint below.

Which phones work?

Android 7.0 or newer with a 64-bit processor (arm64), which covers almost every phone made since 2018. Very old 32-bit phones and x86 emulators are not supported by this build.

Is there an iPhone version?

Not yet. For now ReturnIt is available for Android only.

How do updates work?

Come back to this page and install the new file over the old one; your data stays. When a version is required, the app tells you and links here.
